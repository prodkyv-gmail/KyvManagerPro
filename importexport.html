Backup & Ripristino locale database

Scarica sul PC una copia JSON delle tabelle Supabase oppure ripristina dati da un backup locale. Il ripristino è non distruttivo: non cancella dati esistenti e, di default, salta i duplicati.

Backup locale

Crea un file tipo kyv-db-backup-2026-06-30.json con metadata, schema logico e righe delle tabelle. È utile prima di import pesanti, modifiche massive o migrazioni.

Ripristino controllato

Legge il JSON dal PC, mostra le tabelle trovate e ti fa scegliere cosa reinserire. Il sistema prova a saltare record già presenti tramite ID, chiavi naturali e confronto completo.

Metodo consigliato

Fai sempre un backup prima di importare. Per ripristini su database già popolato lascia attivi “salta duplicati” e “mantieni ID backup” solo se vuoi preservare collegamenti tra tabelle.
