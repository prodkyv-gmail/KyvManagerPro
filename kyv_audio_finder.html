Preparazione…

Google Drive

Usa il connettore Drive attuale. La ricerca può essere limitata dal numero di pagine.

Dropbox

Indicizza i file già registrati in KYV. Il pulsante Scegli usa il Dropbox Chooser ufficiale: apre una finestra di scelta di file, non un crawler di tutto l'account. Apri Archivio Dropbox

Cartella Mac / PC

L’app legge solo cartelle o file che selezioni. Su iPhone usa il selettore File: non è un crawler permanente. Funziona anche su cartelle OneDrive sincronizzate.

OneDrive online

Collegamento diretto Microsoft non ancora attivo. Puoi già indicizzare file dalla cartella OneDrive sincronizzata e autorizzata sul computer.

In una fase successiva sarà possibile collegare OneDrive con autorizzazione OAuth e Microsoft Graph.

Verifica i file trovati — nessun progetto automatico

Per ciascun file scegli se è un tuo lavoro, una reference/brano di altri oppure da verificare. Solo gli audio marcati esplicitamente come tuoi entreranno nel catalogo. Non presumo che un file sia tuo dal nome o dalla cartella.

Coda proposte · v2.46

Trova i possibili brani nei file già indicizzati. Nessuna associazione viene creata automaticamente. I titoli ambigui richiedono una scelta esplicita.

Spunta solo i file verificati. Il salvataggio usa un unico inserimento per il gruppo; «Scollega» annulla poi i singoli legami.

Brani e versioni · v2.49

I file che hai approvato come tuoi vengono raggruppati per nomi simili, per vedere demo, mix, master e altre versioni insieme. È solo una proposta, non una conferma che appartengano allo stesso brano. Non vengono creati nuovi progetti o collegamenti automaticamente.
