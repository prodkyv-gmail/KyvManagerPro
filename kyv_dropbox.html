Dropbox + Supabase

Archivio Audio & Invii Dropbox

Dropbox conserva il file audio. Supabase conserva link, hash, progetto, versione, storico invii, canale, destinatario e conferme. L’invio resta manuale/assistito: copia messaggio, WhatsApp o mail.

Tabelle v2.6 non trovate

Prima di usare il nuovo archivio audio, esegui SUPABASE_MIGRATION_V2_6.sql nel SQL Editor di Supabase. Fino ad allora la pagina non può salvare lo storico strutturato.

Registra file audio

Scegli un file già caricato su Dropbox o incolla il link. Poi seleziona lo stesso file locale per calcolare l’hash SHA-256.

L’hash viene calcolato nel browser. Il file audio non viene caricato su Supabase: su Supabase si salva solo impronta, link e metadati.
