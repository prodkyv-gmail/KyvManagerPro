# Pipeline & Opportunità — v2.28

La pipeline interpreta i campi esistenti della tabella `PROGETTI` e assegna ogni progetto a una fase operativa senza modificare `STATO` o `SVILUPPO`.

Ordine delle fasi: Idea → Sessione → Inviato → In ascolto → Interessamento → Contratto → Produzione → Master → Uscito.

La vista supporta ricerca, filtri per artista, label/management, priorità e follow-up, conteggi per fase e collegamento diretto alla Scheda Progetto.
